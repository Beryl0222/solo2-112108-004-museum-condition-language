# 巡展归还前的双语状况记录核对

巡展交接工作簿保存入场至退场的双语登记、不同照相参照以及箱组合。所有人名、编号和业务记录都是合成数据。

使用 Python 3.11 和标准库，资料文件采用 UTF-8。业务资料的格式记录在 [资料说明](资料说明.md)。

## 资料自检

```sh
python3 read_materials.py
python3 -m unittest discover -s tests -v
```

## 归还前核对工具 `loancheck`

`loancheck` 是可按借件批次反复使用的核对工具，直接读取 `data/` 下的四套 JSONL，
不依赖第三方库。建议用隔离模式运行，避免资料目录中的同名模块被解释器加载：

```sh
python3 -I loancheck_cli.py check  --data data            # 整批核对，机器可读 JSON
python3 -I loancheck_cli.py parse  --data data            # 只看文字解析结果
python3 -I loancheck_cli.py packet --data data --out 交接包.md
python3 -I loancheck_cli.py receipt L1 --data data        # 单件回查收据
python3 -I loancheck_cli.py check --data data --strict    # 有阻断箱时退出码 1
```

### 工具落地的业务规则

1. **五要素抽取并留原文证据**：部位、相对朝向、材质层、状态家族、肯定程度，
   每条观察附报告登记号、原文小句、字符区间和照片号。
2. **三个层面分开**：作品本体（paper/cloth）、装裱（mount）、外箱（crate）。
   同义术语只在声明材质下对应，例如英文 `line` 仅在纸本/织物本体语境与
   `crease/fold` 同义；装裱投影、反光不是损伤。
3. **照片参照按轴解释**：`right_in_object/top_in_object` 决定照片右、上轴
   落在物件的哪一方位；镜像、旋转都按轴换算。英文表格裸写的 `right margin`
   按**照片坐标**处理，不能直接当作画作右缘。照片缺参照时位点保持未解析，
   不与旧痕硬配，并给出“补带方向参照照片”的最少补核项。
4. **三类后果分开**：
   - 入场已签认旧痕（`old_signed`）与入场/展中记录旧痕（`old_recorded`）；
   - 待确认新痕（`new_pending`）、归属分歧（`disputed`）、缺参照未定位
     （`unresolved_located`）阻断放行；
   - 独立复查排除（`review_excluded`）与光学现象（投影/反光）留证但不阻断。
5. **合并不受语言和阶段限制**：多条中英描述可指向同一旧痕；一条笼统的
   “左上和右下各一处”按有证据的位置拆成两条。笼统的“边缘两处起翘”只形成
   旧痕**计数配额**，只能吸收未定位描述，不能抵消已明确记录的新位点。
6. **独立来源按报告登记号计**：同一张照片的不同转述不是互相独立的确认；
   背面/verso 复查、另一视角或另一登记来源才算独立。保护人员的展中清点
   可用于消除歧义。
7. **最少补核视角**：对仍不能确定归属的变化，按特征给出最少还需核对的
   视角或层面（方向参照照片、verso/装裱复查、独立来源复核），同照片转述
   不会被重复计数。
8. **封箱组合与签字绑定**：签收对象是实际可放行的“箱号+借件号组合”，
   每个组合有稳定指纹。拟箱/拟改组记录不能代替签字；物件重新组合后必须
   重新签字，旧签字不得套用到不同组合。
9. **放行条件**：发现归还中的新变化时，只有所需复核均已完成且与当前组合
   一致，受影响的箱才可放行。外箱层变化若有“未达本体”证据，记为
   `case_note` 留痕但不阻断本体放行。
10. **回查收据**：按借件号可查出实际（拟）离馆的物件、放行组合指纹，以及
    离馆时区分旧痕与新增变化所依据的报告和照片证据。

### 合成批次的预期结论

| 箱 | 组合 | 结论 | 主要原因 |
| -- | ---- | ---- | -------- |
| C1 | L1、L2 | 阻断 | 仅“拟合箱”无签字；L2 右下新位点复核未完成 |
| C2 | L3 | 放行 | 封箱签字与组合一致，recto 未见新增 |
| C3 | L4 | 阻断 | 仅“拟改组”无签字（外箱划痕已降为 case_note 留痕） |

其中 L1 的“照片右侧旧折”经镜像照片 V12 换算回物件左上旧折；V13 缺方向参照，
其疑似新线由 O2 的背面复查独立排除为装裱投影，不记为运输新增。

## 目录

- `loancheck/`：核对工具包（模型、词表、解析、几何换算、核对、封箱、CLI）
- `loancheck_cli.py`：命令行薄封装，支持 `python3 -I`
- `tests/`：单元测试与基于合成资料的端到端测试
- `data/`：合成业务资料（JSONL + 字段索引）
